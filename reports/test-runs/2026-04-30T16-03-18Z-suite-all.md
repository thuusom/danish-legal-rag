## Failures → bugs filed

### #96 — chat e2e tests wait for visible references in collapsed panel

- Tests: `chat.spec.ts::chat: golden path` and `chat.spec.ts::chat: law filter scopes`
- Root cause: tests use `toBeVisible()` / `waitForSelector` for
  `a[href*="retsinformation.dk"]`, but the references panel is
  collapsed (`hidden`) by default. Links exist in the DOM (12
  resolved instances per Playwright trace) but are not visible.
- This is a **test bug, not a product bug**. The chat works correctly:
  - API returns 3 references with valid `source_url`
  - Streaming endpoint produces a `references` SSE event
  - Frontend renders the links with the right attributes
  - `<a href="https://www.retsinformation.dk/eli/lta/2016/1147">Afskrivningsloven § 65</a>` is in the DOM
- Fix: change tests to use `toBeAttached()` or `count() > 0` rather
  than `toBeVisible()`. Tester owns this fix (flaky-test label).
- Filed at: https://github.com/thuusom/danish-legal-rag/issues/96
- Assigned to: tester for fix; PM does not need to triage (test
  is buggy, not the code)
