## Architecture decisions

- **ADR-002** (`docs/adr/ADR-002-client-side-session-storage.md`): localStorage
  chosen over server-side storage. No auth system exists, and the tool is
  single-user. Trade-off: sessions do not survive browser clear or cross-device use.

## How to run the full stack locally

```
docker compose down -v && docker compose up --build
```

Then visit `http://localhost:5173` for the chat UI, or run `npm run dev` in
`frontend/` for HMR during development.
